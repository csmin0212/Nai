# 자료 추가하는 법

플레이어 자료는 전부 `data/handouts.js` 한 파일에 들어 있습니다. 이 파일만 편집하면 두 판(`index.html`, `keeper.html`)에 동시에 반영됩니다.
(빌드 과정 없음 — 저장하고 브라우저 새로고침)

> **원칙:** 여기에는 손에 넣은 문서의 원문과, 그 원문에서 읽어 낼 수 있는 내용만 적습니다.
> 캐릭터가 아직 모르는 사실은 넣지 않습니다.

## 1. 핸드아웃 추가

`handouts: [ ... ]` 배열에 아래 틀을 복사해 넣으세요. 쉼표를 빠뜨리지 않도록 주의.

```js
{
  id: "us-09",                  // 고유 ID. "챕터-번호" 규칙. 주소창 #us-09 로 바로 열 수 있음
  chapter: "us",                // chapters 배열의 id 중 하나
  type: "news",                 // news | telegram | dossier | letter | note | photo
  title: "자료 제목",            // 목록·검색용 제목
  headline: "지면에 인쇄된 제목", // (선택) 신문 헤드라인. 없으면 title 사용
  source: "런던 타임스",         // (선택) 출처
  date: "1925-01-20",           // 정렬·연표용. 반드시 YYYY-MM-DD
  dateLabel: "1925년 1월 20일",  // 화면에 보여줄 날짜 표기
  stamp: "CONFIDENTIAL",        // (선택) 문서 위에 찍히는 붉은 도장
  summary: "카드에 보이는 한두 줄 요약.",
  tags: ["칼라일 탐사대", "단서"],
  people: ["잭슨 엘리어스"],     // people 배열의 name 과 똑같이 적으면 인물 화면에서 연결됨
  places: ["런던"],
  body: `본문.

빈 줄로 문단을 나눕니다.

### 소제목

- 목록 항목
- **굵은 글씨**도 됩니다.`
}
```

### 유형(type)별 겉모습

| type | 렌더링 |
|---|---|
| `news` | 신문 지면 — 제호, 겹줄 헤드라인, 2단 조판, 드롭캡 |
| `telegram` | 전보 용지 — 타자기 서식 + 손글씨체 본문 |
| `dossier` | 서류철 — 테두리 액자, 가운데 정렬 표제 |
| `letter` | 편지지 — 오른쪽 위 발신지/날짜, 파란 잉크, 손글씨 서명 |
| `card` | 명함 — 아르누보 장식 문양, 가운데 정렬 |
| `matchbook` | 성냥갑 — 주황 표지, 흰 띠에 문구, 갈색 점화면. `motto` 로 띠 문구 지정 |
| `map` | 지도 — **'지도' 탭에 따로 실립니다.** 아카이브·연표에는 나오지 않습니다 |
| `note` | 타자기 메모 |
| `photo` | 기본 문서 |

`letter` 는 `letterMeta` 로 편지 형식을 지정합니다(전부 선택).

```js
letterMeta: {
  place: "이집트 카이로",       // 오른쪽 위 발신지
  when:  "1919년 3월 3일",      // 오른쪽 위 날짜
  to:    "칼라일 선생님께",      // 첫머리 호칭
  from:  "워런 베사르 드림",     // 맺음말
  signature: "M. Warren Besart" // 손글씨체로 찍히는 서명
}
```

`map` 은 `legendGroups` 로 범례를 넣습니다.

```js
legendGroups: [
  { title: "범례", items: [ { n: 1, name: "뉴욕 대학" } ] }
]
```

범례에 적은 이름은 검색에 걸립니다.

신문 기사는 `subheads`(작은 표제 여러 줄)와 `byline`(기자 이름)을 넣을 수 있습니다.
물건류에는 `objectNote` 로 "생김새가 어떻더라" 하는 설명을 덧붙일 수 있습니다.

### 날짜 없는 자료

`date` 를 아예 빼면 연표의 **'시기 미상'** 칸으로 갑니다. 날짜를 알게 되면 그때 채우면 됩니다.

## 2. 인물 · 장서

`people` 배열에 인물을, `library.books` 배열에 잭슨 엘리어스의 저작을 추가합니다.

- `status` 는 `alive` / `dead` / `missing` 중 하나. 테두리 색이 달라집니다.
- `statusText` 로 실제 문구를 직접 정할 수 있습니다. (예: `"사망 — 1925년 1월, 뉴욕"`)
- `desc` 에도 자료에서 확인한 내용만 적습니다. 추측이면 "…로 보인다"처럼 추측인 티를 내 두면 나중에 헷갈리지 않습니다.

## 3. 새 챕터 열기

지금은 `chapters` 에 미국(`us`) 하나만 있습니다. 다른 지역 자료를 받으면 이렇게 추가하세요.

```js
{ id: "london", name: "런던", en: "LONDON", order: 2 }
```

핸드아웃이 하나라도 들어가면 챕터 필터 버튼이 자동으로 나타납니다.

## 4. 키퍼 메모 (`data/keeper-notes.js`)

`keeper.html` 에서만 읽는 별도 파일입니다. `index.html` 은 이 파일을 아예 불러오지 않습니다.

```js
window.MASKS_KEEPER = {
  "us-01": `이 자료에 붙일 키퍼 전용 메모.`
};
```

핸드아웃 `id` 를 열쇠로 씁니다. 메모가 있는 자료는 카드 왼쪽에 붉은 띠가 생깁니다.
